# SysAdministrations Tools
> A lightweight, cross-platform server monitoring, alert & maintenance agent written in Go.

[![Go Report Card](https://goreportcard.com/badge/github.com/JunDevX/sysadmin-toolkit)](https://goreportcard.com/report/github.com/JunDevX/sysadmin-toolkit)
[![GitHub release](https://img.shields.io/github/v/release/JunDevX/sysadmin-toolkit)](https://github.com/JunDevX/sysadmin-toolkit/releases)

## Features:
- Editing network DNS records
- Managing network hosts
- Port configuration
- Managing consumption and more (not yet available)
